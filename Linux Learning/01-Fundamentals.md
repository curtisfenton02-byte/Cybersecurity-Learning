# What is Linux?
Linux is an operating system similar to Windows, iOS and MacOS. Linux is one of the most popular operating systems in the world, powering smart cars, android devices, supercomputers, home appliances, enterprise servers, and more.
# Where is Linux Used?
Linux powers such things as:
- websites.
- car entertainment/control panels.
- Point of Sale (PoS) systems such as checkout tills and registers in shops.
- critical infrastructure such as traffic light controllers or industrial sensors.
# Flavours of Linux
The name Linux is an umbrella term for multiple OS’s that are based on UNIX (another operating system). Thanks to Linux being open-sources, variants of Linux come in all shapes and sizes – suited best for what the system is being used for.
Common distributions of Linux include:
-Ubuntu
-Debian
# Why is Linux used in Cyber Security?
Linux is widely used in Cybersecurity because it provides security professionals with more control, flexibility and access to powerful tools than most other operating systems do.
The 5 main reasons I believe Linux is important for security professionals:  
- most servers on the internet run Linux. This includes popular servers like Google, Amazon, Meta and Netflix. As a result, if hackers attempt to target Linux servers, defenders need to understand how Linux works to prevent/re-pair attacks.
- Linux is open source, meaning that the code is publicly available and therefore easier/safer for security researchers to inspect and implement security fixes.
- Linux contains a very strong terminal (shell) which allows cybersecurity tasks to be performed much quicker through the command line. Plus automation can be set up for repetitive work needed to help with incident response and penetration testing.
- most security tools are built for Linux. These include:
1. Nmap
2. Wireshark
3. Metasploit
- every file within Linux has strong permission rules which helps administrators restrict access precisely. 
# Why is the terminal important?
- The terminal allows users to communicate directly with the operating system by typing commands instead of clicking buttons.
- The terminal is faster as instead of having to click through multiple folders, users can type one command which does the same job.
-Certain tasks are only possible or at least much easier from the terminal. This includes, creating users, changing file permissions, monitoring running programs and etc.
-Users can automate work with scripts.
-Many Linux servers don’t have a desktop environment and instead administrators connect remotely using ssh.
