## Inline Code

The `pwd` command displays the current working directory.

The `ls` command lists files and folders.

The `cd` command changes directory.

---

## Code Blocks

```bash
pwd
ls
cd Documents
mkdir LinuxNotes
touch notes.md
```

Another example:

```bash
sudo apt update
sudo apt install git
```

## Tables

| Command | Purpose |
|---------|---------|

| `cd` | Change directory |
| `mkdir` | Create a directory |


---

## Key Takeaways

- `#` creates the document title.
- `##` creates major sections.
- `###` creates subsections.
- Use blank lines between paragraphs.
- Put commands inside code blocks.
- Use tables to compare commands.
- Use checklists to track progress.
