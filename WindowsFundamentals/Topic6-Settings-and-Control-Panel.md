# Settings and Control Panel

On a Windows system, the two primary locations to make changes are the Settings menu and the Control Panel.

Before the Settings menu, people often used the Control Panel to make system changes. However, since its introduction in Windows 8, the Settings menu has gradually become the primary location a Windows user goes to if they are looking to change the system.

There are still similarities and differences between the two menus.

## The Control Panel

The **Programs** section of the Control Panel is where we will find applications installed on the system. Then, if we select **Programs and Features**, Windows will provide these applications in a detailed list format. This list will comprise their names; publishers; versions; size and installation date.

The Control Panel is the menu where we will access more complex settings and perform more complex actions.
