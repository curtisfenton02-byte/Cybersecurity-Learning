# The Windows/System32 Folders

The Windows folder (C:\Windows) is traditionally known as the folder which contains the Windows operating system.

This folder doesn't have to reside within the C drive necessarily. In fact, it can reside within any drive and folder.

## Environmental Variables

Environmental variables store information about the operating system environment. Such information includes specific details regarding:

- The operating system path.
- The number of processors used by the operating system.
- The location of temporary folders.

In fact, the system environment variable for the Windows directory is `%windir%`.

## System32

There are many folders within the Windows folder, one of which is the **System32** folder. This folder holds the important files which are critical for the operating system.

Accidentally deleting any files or folders with System32 can render the Windows OS inoperative. 

As a result, it is imperative that we proceed with extreme caution when interacting with this folder.
